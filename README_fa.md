## دربارهٔ پروژه

Resio یک رزومه‌ساز دوزبانه برای متخصصان فنی، مهندسی و دانشگاهی است. این برنامه ۱۰۰٪ سمت کلاینت اجرا می‌شود: نه بک‌اندی وجود دارد، نه حساب کاربری، و حتی یک بایت از داده‌های کاربر هرگز دستگاهش را ترک نمی‌کند. هر فیلد دو مقدار مستقل فارسی و انگلیسی ذخیره می‌کند و سند نهایی برای هر زبان خروجی، با چیدمان درست (راست‌به‌چپ یا چپ‌به‌راست) رندر و اکسپورت می‌شود.

## ویژگی‌ها

**دوزبانه از پایه**

- هر فیلد دو مقدار جداگانهٔ `{fa, en}` ذخیره می‌کند و هیچ‌گاه مقادیر دو زبان با هم ترکیب نمی‌شوند.
- رندر RTL/LTR مستقل برای هر زبان خروجی، همراه با پیش‌نمایش زندهٔ A4 که با یک کلیک بین دو زبان جابه‌جا می‌شود.
- رابط کاربری کاملاً دوزبانه: فارسی (راست‌به‌چپ، پیش‌فرض) و انگلیسی (چپ‌به‌راست).

**محتوا و بخش‌ها**

- ۲۰ بخش استاندارد — اطلاعات شخصی، خلاصه، مهارت‌ها (با ۱۸ دستهٔ پیش‌فرض مهندسی)، سوابق شغلی، تحصیلات، پروژه‌ها، پژوهش‌ها، مقالات، کنفرانس‌ها، گواهینامه‌ها، افتخارات، زبان‌ها (با سطح CEFR)، دوره‌ها، کار داوطلبانه، عضویت‌ها، تدریس، اختراعات، علایق، سرگرمی‌ها و معرف‌ها — به‌علاوه بخش‌های سفارشی نامحدود.
- بسته‌های شروع رشته‌محور: در لحظهٔ ساخت رزومه، محتوای نمونه و دسته‌بندی مهارت‌ها متناسب با رشتهٔ انتخابی پر می‌شود (نرم‌افزار، برق، عمران، مکانیک، پزشکی، دانشگاهی)، تا هیچ‌کس با صفحهٔ خالی شروع نکند. هر فیلد ویرایش هم مثال آماده دارد.

**قالب‌ها**

- ۱۶ قالب — مینیمال، مدرن، حرفه‌ای، مهندسی، فنی، دانشگاهی، پژوهشی، اجرایی، جمع‌وجور، خلاقانه، شیک، فارغ‌التحصیل، استارتاپی، طراحانه، کلاسیک و پزشکی — هر قالب همراه با امتیاز سازگاری با سیستم‌های ATS.

**ویرایش راحت**

- جابه‌جایی کشیدنی (Drag & Drop) بخش‌ها و آیتم‌ها؛ نمایش/مخفی‌کردن هر بخش.
- ذخیرهٔ خودکار با نشانگر وضعیت ذخیره؛ مدیریت چند رزومه در یک داشبورد.
- تقویم میلادی یا شمسی، اعداد فارسی، کلیدهای نمایش عکس و آیکون.
- سنجهٔ تکمیل بودن: چک‌لیست وزن‌دار (اطلاعات تماس ناقص، خلاصهٔ کوتاه، دستاوردهای بدون عدد، مهارت‌های کم، تخمین تعداد صفحات) که هر گزینه‌اش مستقیم به بخش مربوط لینک می‌شود.

## خروجی‌ها

| فرمت | نحوهٔ تولید | نکته |
| --- | --- | --- |
| **PDF** | مسیر اختصاصی چاپ مرورگر | هندسهٔ دقیق A4 یا Letter |
| **Word** (`docx`) | تولید کامل در مرورگر با [`docx`](https://github.com/dolanmiu/docx) | پشتیبانی درست از راست‌به‌چپ |
| **HTML** | تک‌فایل مستقل | روی هر دستگاهی باز می‌شود |
| **XeLaTeX** | بستهٔ آمادهٔ کامپایل | برای هر دو زبان |
| **JSON** | اعتبارسنجی‌شده با [Zod](https://zod.dev/) | پشتیبان‌گیری، بازیابی و انتقال بین دستگاه‌ها |

## حریم خصوصی و نگهداری داده‌ها

همهٔ داده‌ها فقط در `localStorage` مرورگرِ همان دستگاهی ذخیره می‌شود که برنامه روی آن اجراست. **هیچ داده‌ای روی GitHub یا هر سرور دیگری ذخیره نمی‌شود** و هیچ درخواستی به هیچ‌جا ارسال نمی‌شود.

> [!WARNING]
> در نسخهٔ تحت وب، پاک‌کردن داده‌های مرورگر یا تغییر دستگاه به معنای از دست رفتن داده‌هاست. پیش از هر کار حساس، یک پشتیبان بگیرید (**تنظیمات ← پشتیبان‌گیری**). برای جابه‌جایی داده‌ها بین نسخهٔ وب و نسخهٔ محلی هم، از یک نسخه خروجی بگیرید و در نسخهٔ دیگر بازیابی کنید.

## شروع سریع

پیش‌نیاز: [Node.js](https://nodejs.org/) نسخهٔ ۱۸٫۱۸ یا جدیدتر و npm.

```bash
git clone https://github.com/a-bagheri/resio.git
cd resio
npm install
npm run dev
```

سپس [http://localhost:3000](http://localhost:3000) را باز کنید؛ برای اجرا و توسعهٔ محلی هیچ تنظیم اضافه‌ای لازم نیست.

## تنظیمات

برنامه به هیچ متغیر محیطی الزامی نیاز ندارد. دو متغیر اختیاری، بیلد استاتیکِ مخصوص GitHub Pages را کنترل می‌کنند (نمونه در [`.env.example`](.env.example)):

| متغیر | مقدار پیش‌فرض | توضیح |
| --- | --- | --- |
| `NEXT_PUBLIC_BASE_PATH` | خالی | زیرمسیر انتشار؛ برای مخزن پروژه‌ای مثل `/resio` و برای مخزن `<user>.github.io` خالی |
| `STATIC_EXPORT` | خاموش | با مقدار `1` بیلد به‌جای خروجی سروری، خروجی استاتیک در `.next-export/` می‌سازد |

## استقرار در GitHub Pages

فایل [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) با هر push به شاخهٔ `main` بیلد استاتیک می‌گیرد و منتشر می‌کند:

1. یک‌بار از مسیر **Settings ← Pages ← Source ← GitHub Actions** فعالش کنید.
2. همین؛ مسیر پایه (basePath) به‌طور خودکار از نام مخزن تشخیص داده می‌شود.

برای تست محلی خروجی استاتیک:

<div dir="ltr">

```bash
export MSYS_NO_PATHCONV=1   # فقط در Git Bash ویندوز لازم است
STATIC_EXPORT=1 NEXT_PUBLIC_BASE_PATH=/resio npm run build:static
node scripts/serve-out.mjs /resio 3460   # → http://localhost:3460/resio/
```
</div>

```
src/
├── app/                    # صفحات (App Router)

└── lib/                    # منطق دامنه
    ├── types.ts            # مدل دادهٔ دوزبانه و فهرست بخش‌ها
    ├── store.ts            # فروشگاه zustand + ذخیره‌سازی در localStorage
    ├── factory.ts          # سازندهٔ رزومه و بخش‌ها
    ├── professions.ts      # بسته‌های شروع متناسب با هر رشته
    ├── templates.ts        # تنظیمات قالب‌ها و پالت‌های رنگی
    ├── i18n.tsx            # دیکشنری دوزبانهٔ رابط کاربری
    ├── export-docx.ts      # خروجی Word (docx)
    ├── export-html.ts      # خروجی HTML تک‌فایلی
    ├── latex.ts            # خروجی XeLaTeX
    ├── io.ts               # ورود/خروج JSON با اعتبارسنجی zod
    └── score.ts            # سنجهٔ تکمیل بودن رزومه
```

## بومی‌سازی: زبان و تاریخ

- رابط کاربری کاملاً دوزبانه است: فارسی (راست‌به‌چپ، پیش‌فرض) و انگلیسی (چپ‌به‌راست)؛ تغییر زبان از هدر و ذخیره در همان مرورگر.
- محتوای رزومه در دو زبان به‌صورت مستقل نوشته می‌شود و برای هر زبان خروجی جداگانه رندر و اکسپورت می‌شود.
- تاریخ‌ها بر اساس تنظیمات طراحی: میلادی، شمسی یا فقط سال — با اعداد فارسی در خروجی فارسی.

## بررسی کیفیت

هنوز مجموعه‌تست خودکاری وجود ندارد؛ بررسی‌های فعلی:

<div dir="ltr">

```bash
npx tsc --noEmit        # بررسی نوع‌ها در کل پروژه (باید بدون خطا بگذرد)
npm run build:static    # کامپایل تولیدی + خروجی استاتیک
```
</div>
